# philornis_lcWGS_data_processing
Scripts for processing low-coverage whole-genome sequencing (lcWGS) data from Philornis downsi, adapted from the [Physalia lcWGS pipeline](https://github.com/nt246/physalia-lcwgs/tree/main). Workflows include read quality control, trimming, mapping, duplicate removal, and depth-of-coverage calculations. These shared scripts support multiple research projects, with paper-specific analyses maintained in separate repositories.
